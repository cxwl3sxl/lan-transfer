# 局域网互传 (LAN Transfer)

[![Python](https://img.shields.io/badge/python-3.8+-blue.svg)](https://www.python.org/)
[![Platform](https://img.shields.io/badge/platform-Windows-lightgrey.svg)](https://www.microsoft.com/windows)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

同一局域网（通常是同一个 WiFi）下，其他人用手机扫描二维码打开网页，即可向本机发送**文字**和**文件**。本机实时接收、保存，无需安装任何 App，无需注册账号。

## ✨ 功能

| 功能 | 说明 |
|---|---|
| 📱 扫码即用 | 终端和网页同时显示二维码，手机扫码打开网页即可发送 |
| 💬 发送文字 | 文字内容实时显示在接收端 |
| 🔗 链接可点击 | 文字中的 `http(s)://` 与 `www.` 链接自动识别为可点击链接，点击后在**新窗口**打开 |
| 📎 发送文件 | 支持多文件、拖拽上传、进度条显示 |
| 📥 自动保存 | 文字记入用户目录下的 `LanTransfer/received/history.jsonl`，文件保存到 `LanTransfer/received/files/` |
| 📅 日历视图 | 按日期查看收到的内容，日历上标有收到内容的日期 |
| 🧹 一键管理 | 清空记录 / 打开接收文件夹 / 复制链接 |
| 🪟 托盘模式 | 最小化到系统托盘，右键菜单操作，支持开机自启 |
| 🌐 标题抓取 | 发送链接时自动抓取网页标题并展示 |

## 🚀 快速开始

### 方式一：双击 exe（无需安装 Python）

`dist/` 下有两个打包好的独立可执行文件，直接双击即可运行（首次可能被防火墙提示，放行即可）：

| 文件 | 说明 |
|---|---|
| `LanTransfer.exe` | 控制台版：弹终端窗口显示二维码，`Ctrl+C` 停止 |
| `LanTransferWindowed.exe` | **托盘版（推荐）**：无黑框窗口，最小化到系统托盘，右键托盘图标可「打开接收页面 / 复制链接 / 打开接收文件夹 / 退出」 |

收到的文件保存在用户主目录下的 `LanTransfer/received/files/`（如 `C:\Users\你的用户名\LanTransfer\received\files\`）。

### 方式二：双击脚本

1. 双击 `start.bat`
2. 首次运行会自动安装依赖 `qrcode`
3. 服务启动后，终端会显示二维码，浏览器会自动打开接收页面
4. 用手机扫描二维码，即可发送文字/文件

### 方式三：手动命令

```bash
pip install -r requirements.txt
python lan_transfer.py
```

可选参数：

```bash
python lan_transfer.py 9000           # 指定端口（默认 12666）
python lan_transfer.py --no-browser   # 不自动打开浏览器
python lan_transfer.py --windowed     # 托盘模式（需 pip install pystray pillow）
python lan_transfer.py --data-dir D:\MyData   # 指定接收数据存放目录
```

### 端口规则

- **默认端口 12666**。
- 若 12666 被占用，会在其之上（12667~13666）**随机**取一个可用端口，启动时会提示：
  ```
  [提示] 端口 12666 被占用，已随机改用端口 12770
  ```
- 托盘版同样会在启动通知里说明端口变更。
- 手动指定端口时规则相同：优先用你指定的，被占用则在它之上随机取。

## 📖 使用说明

- **发送方**（手机/其他电脑）：扫描二维码 → 打开网页 → 在「发送」页输入文字或选择文件。
- **接收方**（运行本程序的电脑）：自动打开的「接收」页里可以看到二维码、收到的文字和文件，点击文件可下载。
- 收到的文字里如果包含网址（如 `https://www.baidu.com`、`www.qq.com`），会自动变成蓝色下划线链接，点击即在浏览器新标签页打开，链接末尾的中文标点（`。，、）`）不会被吞进网址。
- 收到的文件默认存放在用户主目录下的 `LanTransfer/received/files/` 目录，可在网页里点「打开接收文件夹」直接打开。

## 🔧 配置

### 代理设置

程序会自动选择网络通道：

- **公网地址** → 走**系统代理**（Windows 读系统代理设置，其他平台读 `http_proxy` / `https_proxy` 环境变量），因此必须通过代理才能访问的站点也能解析。
- **本机 / 局域网地址**（`localhost`、`127.*`、`192.168.*`、`10.*`、`.local` 等）→ **直连**，避免被代理拦截、也避免内网地址泄漏到外部代理。
- 首选通道失败时，会**自动换另一种通道重试一次**（代理挂了仍能直连，反之亦然）。

如果系统代理用的是 **PAC 自动配置脚本**（程序读不到具体代理地址），可用环境变量显式指定后再启动：

```bash
# Windows CMD
set LAN_TRANSFER_PROXY=http://127.0.0.1:7890
LanTransfer.exe

# PowerShell
$env:LAN_TRANSFER_PROXY="http://127.0.0.1:7890"; .\LanTransfer.exe
```

代理需要账号密码时写成 `http://user:pass@127.0.0.1:7890`。设置了该变量后，除本机/内网外的所有标题请求都会经它转发。

## ❓ 常见问题

### 1. 手机打不开 / 扫了没反应

- 确认手机和电脑连接的是**同一个网络**（同一个 WiFi / 路由器）。
- 部分路由器开启了「AP 隔离 / 客户端隔离」，会禁止设备互访，需在路由器后台关闭。
- 确认电脑 IP 是局域网地址（如 `192.168.x.x`），而不是 `127.0.0.1`。

### 2. Windows 防火墙拦截

首次运行时 Windows 可能弹出防火墙提示，请勾选「专用网络」并点击「允许访问」。若已误拒绝：

```
控制面板 → Windows Defender 防火墙 → 允许应用或功能通过防火墙
→ 找到 Python 并勾选「专用」网络
```

### 3. 二维码在终端显示为乱码

终端二维码只是辅助，请直接看自动打开的浏览器网页里的二维码，或把网页里的链接手动发给对方。

### 4. 想改端口

```bash
python lan_transfer.py 9000
```

注意端口是**随机回退**的，所以每次启动可能不一样，请以启动时显示的「扫码地址」为准（手机也要重新扫新的二维码）。

### 5. 链接标题解析失败 / 需要走代理

发送「整段只有一个网址」的消息时，服务端会在后台抓取该网页的 `<title>` 并同步显示；没解析出来时消息下方会出现 **🔄 解析标题** 按钮，可手动重试（失败原因会直接提示，例如超时、HTTP 403、页面无标题）。
